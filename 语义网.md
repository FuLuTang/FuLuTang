# 语义网期中小抄（压缩版）

## 1. RDF / Turtle 速查

### 三元组
    subject predicate object .

- `subject`：IRI / blank node
- `predicate`：**只能 IRI**
- `object`：IRI / literal / blank node

### 前缀
    @prefix iut: <https://cours.iut-orsay.fr/iws/> .
    @prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
    @prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .
    @prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

### Turtle 缩写
    iut:obama a iut:Politicien ;      # a = rdf:type
        iut:naissance "1961-08-04"^^xsd:date ;
        iut:lieuNaissance iut:honolulu ;
        iut:type iut:Personne , iut:President .

- `;`：同一 subject
- `,`：同一 subject + predicate

### Literal
    "bonjour"@fr
    "2025-01-15"^^xsd:date
    "499.99"^^xsd:decimal
    "10452"^^xsd:integer
    "true"^^xsd:boolean

### Blank node
    iut:jen iut:location [
      iut:lat 53.3 ;
      iut:long -9.0
    ] .

### 建模时先分
- **实例**：Obama, Paris
- **类**：Personne, Ville
- **对象属性**：`lieuNaissance`, `villeDans`
- **数据属性**：`dateNaissance`, `prix`

### 关系何时单独建实体
- 关系自己还有属性（开始/结束日期、地点、编号）时  
- 例：**任期 / 合同 / 订单 / 比赛**



## 2. RDFS 速查

### 子类
    A rdfs:subClassOf B .
    x a A .
    => x a B .

### 子类传递
    A rdfs:subClassOf B .
    B rdfs:subClassOf C .
    => A rdfs:subClassOf C .

### 子属性
    p rdfs:subPropertyOf q .
    s p o .
    => s q o .

### domain
    p rdfs:domain C .
    s p o .
    => s a C .

### range
    p rdfs:range C .
    s p o .
    => o a C .

### 高频例子
    iut:capitaleDuPays rdfs:subPropertyOf iut:villeDans .
    iut:dirigePar rdfs:range iut:Chercheur .
    iut:Capitale rdfs:subClassOf iut:Ville .



## 3. SPARQL 速查

### 骨架
    PREFIX iut: <https://cours.iut-orsay.fr/iws/>
    PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>

    SELECT ?x ?y
    WHERE {
      ...
    }
    ORDER BY ?x
    LIMIT 10
    OFFSET 0

### 四类查询
    SELECT ?x WHERE { ... }
    ASK { ... }
    CONSTRUCT { ... } WHERE { ... }
    DESCRIBE ?x WHERE { ... }

### Triple pattern
    ?u a iut:Universite .
    ?u iut:nom ?nom .

### JOIN
    ?region iut:comprend ?dep .
    ?dep iut:comprend ?u .

### OPTIONAL
    OPTIONAL { ?u iut:nomCourt ?short . }

### UNION
    { ?x a iut:Region . }
    UNION
    { ?x a iut:Departement . }

### FILTER
    FILTER(?x != ?y)
    FILTER(?annee >= "1800"^^xsd:gYear)
    FILTER(STRSTARTS(LCASE(STR(?nom)), "institut"))
    FILTER(?t IN (iut:Region, iut:Departement, iut:Commune))

### 聚合
    SELECT (COUNT(?x) AS ?nb) WHERE { ... }

    SELECT ?dep (COUNT(?c) AS ?nb)
    WHERE { ... }
    GROUP BY ?dep
    ORDER BY DESC(?nb)

### 新列
    BIND(CONCAT(STR(?nom), " (", STR(?short), ")") AS ?display)

### 全信息展开
    SELECT ?p ?o
    WHERE { ?x ?p ?o . }

### 推理
- **推理开**：能查到隐含事实
- **推理关**：只能查显式三元组



## 4. 例题速查（只留常用型）

### 4.1 题：课程 / 学校 / 名称 建模
    iut:module1 a iut:Module ;
        iut:enseigneA iut:iutOrsay ;
        rdfs:label "Knowledge Graphs"@en .

### 4.2 题：人物 + 多段任期；任期有开始/结束日期
    iut:obama a iut:Politicien ;
        iut:dateNaissance "1961-08-04"^^xsd:date ;
        iut:aMandat iut:m1 , iut:m2 .

    iut:m1 a iut:Mandat ;
        iut:fonction iut:Senateur ;
        iut:dateDebut "2005-01-04"^^xsd:date ;
        iut:dateFin "2008-11-16"^^xsd:date .

### 4.3 题：商品建模（价格 / 日期 / 库存 / 销量）
    iut:p1 a iut:Produit ;
        iut:prix "499.99"^^xsd:decimal ;
        iut:dateMiseEnVente "2025-01-15"^^xsd:date ;
        iut:enStock "true"^^xsd:boolean ;
        iut:nombreVendu "10452"^^xsd:integer .

### 4.4 题：负责人都是研究员；减少冗余
    iut:dirigePar rdfs:range iut:Chercheur .

效果：
    iut:lisn iut:dirigePar iut:sophie .
    => iut:sophie a iut:Chercheur .

### 4.5 题：已知 `s a o`, `o subClassOf q`, `q subClassOf r`
可推出：
    iut:o rdfs:subClassOf iut:r .
    iut:s a iut:q .
    iut:s a iut:r .

### 4.6 题：已知 `s p o`, `p domain C`, `p subPropertyOf q`
可推出：
    iut:s a iut:C .
    iut:s iut:q iut:o .

### 4.7 题：只补一个三元组，让 `x p y` + `p range T` 推出 `y a S`
补：
    iut:T rdfs:subClassOf iut:S .

### 4.8 题：城市 / 首都 / 国家 建模，并推出“首都属于国家”
    iut:Capitale rdfs:subClassOf iut:Ville .
    iut:capitaleDuPays rdfs:subPropertyOf iut:villeDans ;
                       rdfs:domain iut:Capitale ;
                       rdfs:range iut:Pays .

### 4.9 题：列出所有 region
    SELECT ?region ?nom
    WHERE {
      ?region a iut:Region ;
              iut:nom ?nom .
    }

### 4.10 题：查 1800~1900 建立的大学，并按年份降序
    SELECT ?nom ?annee
    WHERE {
      ?u a iut:Universite ;
         iut:nom ?nom ;
         iut:anneeCreation ?annee .
      FILTER(?annee >= "1800"^^xsd:gYear && ?annee <= "1900"^^xsd:gYear)
    }
    ORDER BY DESC(?annee)

### 4.11 题：查 Île-de-France 的大学；有简称就显示
    SELECT ?nom ?short
    WHERE {
      ?region a iut:Region ;
              iut:nom "Île-de-France"@fr ;
              iut:comprend ?dep .
      ?dep iut:comprend ?u .
      ?u a iut:Universite ;
         iut:nom ?nom .
      OPTIONAL { ?u iut:nomCourt ?short . }
    }

### 4.12 题：和 Orsay 在同一个 département 的 communes
    SELECT ?nom
    WHERE {
      ?dep iut:comprend ?orsay .
      ?orsay a iut:Commune ; iut:nom "Orsay"@fr .
      ?dep iut:comprend ?autre .
      ?autre a iut:Commune ; iut:nom ?nom .
      FILTER(?autre != ?orsay)
    }

### 4.13 题：统计每个 département 的 commune 数量
    SELECT ?nomDep (COUNT(?commune) AS ?nb)
    WHERE {
      ?dep a iut:Departement ;
           iut:nom ?nomDep ;
           iut:comprend ?commune .
      ?commune a iut:Commune .
    }
    GROUP BY ?nomDep
    ORDER BY DESC(?nb)

### 4.14 题：大学最多的前 5 个 region
    SELECT ?nomRegion (COUNT(?u) AS ?nb)
    WHERE {
      ?region a iut:Region ;
              iut:nom ?nomRegion ;
              iut:comprend ?dep .
      ?dep iut:comprend ?u .
      ?u a iut:Universite .
    }
    GROUP BY ?nomRegion
    ORDER BY DESC(?nb)
    LIMIT 5

### 4.15 题：拼接全名和简称成一列
    SELECT ?display
    WHERE {
      ?u a iut:Universite ;
         iut:nom ?nom ;
         iut:nomCourt ?short .
      BIND(CONCAT(STR(?nom), " (", STR(?short), ")") AS ?display)
    }



## 5. 最后速查

### 题目关键词 → 常见写法
- **表示成 RDF** → 实例 / 类 / 对象属性 / 数据属性
- **推理 / inférer** → `subClassOf / subPropertyOf / domain / range`
- **如果有就显示** → `OPTIONAL`
- **同一个 …** → 共享变量 JOIN
- **多少个** → `COUNT`
- **每个 X 有多少** → `COUNT + GROUP BY`
- **前 5 / 最多** → `ORDER BY DESC + LIMIT`
- **拼成一列** → `BIND + CONCAT`
- **所有信息** → `?x ?p ?o`

### 高频坑
- literal 忘写 datatype
- `"Paris"` 和 `"Paris"@fr` 不一样
- `domain` 推 **subject 类型**
- `range` 推 **object 类型**
- `subClassOf / subPropertyOf` **可传递**
- 推理开/关结果不同
